How it works

From link to game in three steps

  1. Pick a game

    Choose a game from the library. It opens in a new browser tab. Nothing to download or install.

  2. Put it on the projector

    Split the class into groups, type in their names, and press Full screen.

  3. Play and talk

    Groups take turns while you run the clock and keep score. Every game ends with results to discuss.

Saving. Games save in the browser you play them in. Use the same computer and browser next class, or use "Save to a file" where a game offers it.
School filters. If a game is blocked at school, ask your IT team to allow this site's address. It collects no student data.
Keyboard shortcuts. Most games use number keys for teams, Space to pause, and F for full screen.
